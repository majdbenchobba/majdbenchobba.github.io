# majdbenchobba.github.io

Personal portfolio for Majd Ben Chobba, an electrical engineer and founder of
Solarna Systems.

The site features Solara, Solarna Systems and SolarnaPV, BiasForge, selected
software projects, education, and creative work. Product source stays in its
own repositories; this repository contains the portfolio and public project
summaries.

## Development

The site uses plain HTML, CSS, and JavaScript and has no build step. With
Python 3.9 or newer, run the local validator from this directory:

```sh
python scripts/validate_site.py
```

GitHub Actions runs the same validator on pull requests and pushes to `main`.
